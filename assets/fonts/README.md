# Fontes locais

Título: **Bree Serif**, TypeTogether. Interface: **Atkinson Hyperlegible**, Braille
Institute of America. Os arquivos originais são distribuídos sem modificações,
com suas licenças SIL Open Font License 1.1 nesta pasta. As duas famílias têm os
acentos usados em português. O jogo e seus formulários não carregam fontes externas.

Fontes e licenças obtidas do repositório oficial Google Fonts:
[Bree Serif](https://github.com/google/fonts/tree/main/ofl/breeserif) e
[Atkinson Hyperlegible](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible).
